ECHO Motion Lab

Seven everyday moments in ECHO, each shown three ways. Press Play all three to run them side by side, or click inside any one to try it yourself. Column A uses ECHO's real timings from today's code.

Your device is set to reduce motion. ECHO follows that setting by default and switches most animations off, which on its own would make everything blink into place. Settings → Motion → Full overrides it. The demos below still play, because you start them.

Which one?

Reply in the terminal with A, B or C, or a mix, like “B, but C for the buttons”. Each demo has a code (1A, 4C, …) if you want to point at one. If something should move that isn't shown here, say that too.
