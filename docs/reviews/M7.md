### Task 1: what the live docs say (2026-10-24)

- **Scopes:** `streaming` is the SDK's scope and needs Premium. `user-read-private` is needed by
  Search and returns `product`. `user-read-email` is needed by nothing ECHO calls, and the SDK
  reference names no scopes. It stays in `SPOTIFY_SCOPES` until the manual check shows playback
  without it.
- **SDK and CSP:** `spotify-player.js` opens a hidden iframe at `sdk.scdn.co/embedded/index.html`
  with `allow="encrypted-media; autoplay"`. ECHO's CSP already allows `sdk.scdn.co` (script, frame),
  `api.spotify.com` (connect) and `i.scdn.co` (img). No change needed.
- **Endpoints (February 2026 guide):** player endpoints unchanged; `GET /me/albums` unchanged;
  saving uses the generic `/me/library`; playlist tracks are `/playlists/{id}/items` (owned or
  collaborative only); search `limit` ≤ 10. New Development Mode apps: 5 users, owner needs Premium.

### Security review findings fixed along the way

- **Credit links from Spicy community syncs** could carry `javascript:` URLs. They are now
  http(s) only, on both the server and the client (`717b062`).
- **Spotify-ID mappings and the lyrics cache** were keyed without the request's ISRC and metadata.
  One user could pin a wrong Spotify id, and so wrong lyrics, on another's track. Both are now keyed
  by what the lookup used (`a81268f`).

### Deviations

- **The Spotify queue sheet mirrors the SDK's `next_tracks`** (the next two), not
  `GET /me/player/queue`. It refreshes on every state change. The full queue read is a follow-up if
  two tracks feel thin.
- **The palette for a Spotify album is cached per cover URL**, not per album. A request naming
  another image cannot repaint an album for other users.
- **`user-read-email` is still requested** until the manual check (task 1 above).
- **Spotify queues are not saved to `/me/queue`.** Spotify keeps its own queue across devices, and
  saving it would overwrite the user's Navidrome queue.
- **No end-of-context "ended" event for Spotify.** Spotify advances its own context, and at the end
  the dock shows the last track paused.
