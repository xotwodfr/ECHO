### Decisions and deviations

- **Device login without Origin.** A request with no Cookie and no Origin may call
  `POST /auth/device`. A native client has neither, and with no cookie there is nothing for a
  forged request to ride on (`SETTINGS_AND_SECURITY.md` §5.3 updated).
- **Deleting a user deletes their audit rows.** One anonymous line (`account.deleted`, user id)
  records the deletion, so no row naming the user remains (SEC-06).
- **Crossfade, film grain and pointer parallax** are shown disabled with "Arrives in a later
  version": they are stored per the spec, but not built.
- **Visual quality** applies the next time the Stage opens (the tier is chosen at mount; the
  governor is M9).
- **The admin user list** has no paging. A household server has few users, and the E2E database
  now clears earlier runs' users.
- **Restore without the key:** TOTP secrets are unreadable, so users sign in with a recovery code
  and enrol again, which needs that recovery code too.
