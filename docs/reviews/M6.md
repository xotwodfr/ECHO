### Task 6: what Navidrome does (Q-LI-4)

The live server (0.64.0) advertises `songLyrics` v1 and v2 and fills `cueLine` from enhanced LRC
(including `[bg:]`) and from TTML; songs carry an `isrc` array. Recorded in
`LYRICS_INTEGRATION.md`.

### Security review findings fixed along the way

- Free-form `navidromeId`/`spotifyId` parameters let one request fill another track's shared cache
  entry with a different song. Ids now come from the track key, and the normalised metadata is part
  of the cache key (`d8708f1`).

### Deviations

- **The server answers 404 at 4.5 s**, so the Cover can appear before the client's 6 s give-up
  (LYR-16 allows "at 6 s"; the client still gives up at 6 s on its own).
- **A late, better source is cached but not pushed** to a client already showing lyrics; the next
  play gets it. §9.5 also allows a swap in the first 10 s or an instrumental gap; that needs a
  server push (or a client re-ask) and is left until real songs show it matters. Likewise a source
  answering after the server's 4.5 s 404 reaches the client only on the next play.
- **Spicy is used only for `spotify:` track keys** until M7 task 8 maps Navidrome tracks to Spotify
  ids.
- **E2E skips use `Ctrl+→`**: the Stage hides its idle chrome, so clicking Next in a loop raced the
  dock's fade.

## Task 7: the real-song tuning pass (owner)

Needs the owner's library and the laptop and gaming PC. Procedure:

1. Pick 10 songs across genres (ballad, rap, fast pop, a song with background vocals, a duet,
   instrumental passages, one non-English, one live recording, one with a long intro, one where
   Navidrome has word-synced LRC).
2. For each, on both machines: note the source chosen (ⓘ menu), whether lines arrive on time, and
   the offset needed (`[`/`]`, the toast shows the total).
3. If most songs need the same offset on one machine, that is output latency: report it, it belongs
   in the latency ring buffer, not in lyric constants.
4. Note word-highlight lead/lag, line hold, and background-vocal placement against
   `LYRICS_EXPERIENCE.md`; I then adjust the constants and update that document.
