## Task 1: `viewStore`, history sync, deep links, shell layout (2026-10-23)

**Status: done.** No M2 acceptance criterion passes from task 1 alone. DS-01 and DS-02 cover every
M2 screen and component and are checked when M2 closes. LIB-01's "grid edges land on both gutters" is
M5 (it needs library data), but the arithmetic is already tested here (below).

### What was built

| Part | Where |
|---|---|
| `viewStore`: Zustand vanilla store. `parseRoute`/`routePath` are pure. `navigate()` pushes (or replaces) a history entry, and `popstate` restores the view. Non-canonical deep links are rewritten in place. Re-selecting the current view adds no entry | `src/client/view.ts` |
| Shell frame (§5): 224px sidebar (wordmark, Listen, Library, 32px Search field with `/` hint, Settings; 34px pitch; active = `--text` on a `--surface-3` 8px pill), no top bar, 32px canvas gutter, 88px full-width dock. Stage (Listen) is full-bleed with no sidebar, and the dock sits over it, transparent. Compact (< 720px): a bottom bar of 4 destinations | `src/client/shell/Shell.tsx`, `src/client/main.css` |
| Album grid with the column arithmetic comment: `columns = floor((W + 16) / (168 + 16))`, via `repeat(auto-fill, minmax(168px, 1fr))` | `AlbumGrid` in `Shell.tsx` |
| UI copy | `src/client/strings.ts` |
| Server: extension-less paths fall back to `index.html` so deep links load directly. Paths with an extension stay 404, so `/specimen.html` is still 404 in the image (DS-10) | `src/server/index.ts` |

Views and their addresses:

| Address | View |
|---|---|
| `/` | Listen (Stage) |
| `/library`, `/library/artists`, `/library/playlists`, `/library/starred` | Library tabs (Albums is the default) |
| `/library/album/:id` | Album detail (S6) |

Also built: focus moves to the new view's `h1` after navigation (except while typing in search),
`document.title` follows the view, and links are real `<a href>`s.

  arithmetic at 1024/1440/2560 (columns, tile ≥ 168px, both edges 32px from the canvas edges),
  frame geometry at the 4 viewports (no horizontal overflow, dock 88px, sidebar 224px or a compact

  `SHOTS=1` writes review screenshots to `shell-shots/`.

### Found and fixed during the task

- An unknown deep link lost its query string (unit test).
- The sidebar search field overflowed the sidebar rule by 8px, because a flex item had no
  `min-width: 0`. Found on the 1440 screenshot. A geometry assertion was added and checked to fail
  without the fix.
- The E2E measurements raced React 19's asynchronous first render under CPU load (1 failure in one
  full run during a parallel Docker build). The tests now wait for the rendered shell. 132/132
  passed in a repeated run under synthetic CPU load.
