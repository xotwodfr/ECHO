### Found and fixed while building

1. **The production CSS minifier rewrites colour tokens** (`oklch(0.68 0.10 75 / 0.35)` →
   `oklch(68% .1 75/.35)`), and the first parser only accepted the written form, so the engine
   failed to start. The parser now accepts every CSS form ECHO's tokens can take, with tests on the
   minified forms. Any start failure now falls back to the CSS room instead of an empty stage.
2. **The room was far too bright** at first: the spec's pool intensities (0.10–0.22) were added
   as linear light and then lifted by the dark-preserving exposure. They are now perceptual
   amplitudes (squared into linear light), which gives a low glow on a dark room.
3. **On the Stage, the dock lost its text, play button and times**: the positioned Stage painted
   over the dock's non-positioned children. The dock now has its own stacking layer.
4. DS-01 flagged duplicated palette literals in the engine; the Stage now reads the tokens.

## Task 6: deterministic mode (2026-10-23)

**Status: open.** Deterministic **time and noise** work (`frame`, `seed`, `tier`). Recorded-feature
playback (`fixture`, VISUALIZER §10) is **not implemented**. That is a gap against §10, not an
approved deferral.

### Two different things

- **Deterministic time and noise (built).** `frame` fixes song time, `seed` fixes the noise, and
  `tier` fixes the DPR cap and room scale. With those, the M2 room is the same image on every load.
  The M2 room reads no audio features, so these three are everything its pixels depend on today.
- **Recorded-feature playback (not built).** §10 defines `fixture` as "a recorded fixture track (a
  JSON of per-frame Features)". No such recordings exist (M3 task 2 hand-authors the first ones).
  ECHO keeps `fixture=` in the URL and logs a console error saying it is not implemented. It
  loads nothing, uses no placeholder Features and is never read as a track id.

### What was built

| Part | Where |
|---|---|
| `/?frame=<ms>&seed=<n>&track=<id>&fixture=<name>&tier=<T0..T3>` is part of the Listen route, so the view store's canonical-URL rewrite keeps it and a reload stays deterministic. `frame` must be a whole number of ms, or the mode is off. A malformed `seed` (→ 0) or `tier` (→ T1), and an empty `track` or `fixture`, are dropped. Defaults are left out. **Params the mode does not use are kept**, in order, after its own (values come back URL-encoded: `a%20b` is written `a+b`) | `view.ts` (`parseFrame`, `routePath`) |
| One frame, no loop. The engine runs in **Still** (no rAF loop), but feeds the room **Ambient's time bases** for `frame`: `flow = 0.05 · t`, `drift = t`. That is the room Ambient would show after `t` of playback at full rate. A plain Still frame (reduced motion) has `flow = drift = 0`. The noise seed comes from `seed` and the tier from `tier` (default T1). There is no governor yet (M9) | `stage/engine.ts`, `shell/Stage.tsx` |
| **`track=`** (ECHO's own param, not in §10): a library track id, cued **paused at `frame`** so the dock shows a fixed track and time. New `controller.cue(tracks, index, context, startMs)`. An unknown id logs an error. Development builds only (the image has no fixture library) | `main.tsx`, `playback/controller.ts` |

### Tests

- Vitest: route params in canonical order. `track` and `fixture` are kept apart. Unrelated params
  are kept, and survive the store's URL rewrite. A malformed `frame` turns the mode off. A
  malformed `seed`/`tier` and an empty `track`/`fixture` are dropped. `cue` stays paused at its
  position.
- Playwright `stage.spec.ts` (**Chromium only**; Firefox skips them because it has no WebGL on this
